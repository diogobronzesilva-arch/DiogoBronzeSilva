VitaChart · Guide et assistance

Les premiers pas
avec VitaChart.

Apprenez à noter vos observations, à consulter votre cycle et à sauvegarder votre journal sur iPhone, Android ou dans la version web.

Pour commencer

Quatre rubriques principales

Vous pouvez utiliser l’application sans compte. À la première ouverture, choisissez la convention de notation adaptée à la méthode que vous suivez.

Aujourd’hui

Situez-vous dans votre cycle et ouvrez le journal du jour.

Saisir

Saisissez les observations, la température, les symptômes et les notes que vous souhaitez conserver.

Cycle

Consultez le graphique, relisez vos observations et préparez un rapport pour la consultation.

Réglages

Gérez les préférences, les rappels, la protection de l’accès et les sauvegardes.

Une routine simple

  1. Vérifiez la date et saisissez uniquement les observations de ce jour-là.
  2. Avant de quitter l’écran, vérifiez que la mention Enregistré est affichée.
  3. Rouvrez la journée et ouvrez Cycle pour revoir l’ensemble de vos observations.

Noter avec Creighton ou Billings.

Depuis la version 1.3.2, chaque méthode possède son formulaire quotidien, son graphique et son rapport. Choisissez la méthode que vous utilisez avec votre formatrice ou votre professionnel de santé.

Modèle Creighton

Notez les observations à l’aide de codes standardisés. Le graphique et l’historique conservent les codes et les symboles d’origine, avec P pour le jour Sommet.

Essayer Creighton →

Méthode de l’Ovulation Billings

Décrivez avec vos mots la sensation vulvaire et les pertes visibles. Vous pouvez consigner le Profil d’Infertilité de Base (PIB) et les changements observés. Le graphique et le PDF Billings présentent ces observations et indiquent le Sommet confirmé par un ×.

Essayer Billings →

Pour la consultation

Préparer un rapport

Sur iPhone et Android

Dans Cycle, choisissez le cycle à consulter et touchez Imprimer / Enregistrer le PDF. Avant de partager, vérifiez les observations et le réglage qui masque les rapports sexuels.

iPhone · Dans le rapport, touchez Enregistrer / Partager le PDF et choisissez la destination dans le menu de partage.

Android · Dans le rapport, touchez Imprimer / Enregistrer le PDF et sélectionnez Enregistrer au format PDF dans le menu d’impression. Vous pourrez ensuite partager le fichier enregistré.

Dans la version web

Ouvrez le rapport du cycle et utilisez l’option du navigateur pour imprimer ou enregistrer au format PDF.

Vous pouvez consulter, imprimer ou partager le PDF. Pour restaurer votre journal dans l’application, gardez aussi un fichier de sauvegarde séparé.

Conserver votre journal

Choisir et enregistrer une sauvegarde

Une sauvegarde exportée vous permet de conserver vos données en dehors de l’application. Enregistrez le fichier dans un emplacement privé auquel vous pourrez accéder de nouveau.

Sauvegarde standard

Réglages → Enregistrer une copie → Enregistrer une sauvegarde

Cette option crée un fichier JSON lisible en texte clair. Il peut inclure votre profil et votre historique, y compris les informations que le mode discret masque sur le graphique.

Sauvegarde avec mot de passe

Dans la rubrique Copie chiffrée et vérification de l’intégrité, renseignez Mot de passe de la copie chiffrée et sélectionnez Exporter une copie chiffrée.

Cette option protège la sauvegarde exportée par un mot de passe. Conservez-le en lieu sûr. Vous pouvez aussi exporter une sauvegarde standard séparément.

Restaurer le journal ou changer de téléphone

  1. Créez une sauvegarde sur l’ancien téléphone et vérifiez que le fichier a bien été enregistré.
  2. Sur le nouveau téléphone, installez VitaChart et ouvrez Réglages → Enregistrer une copie → Charger la sauvegarde (Restaurer).
  3. Sélectionnez le fichier et suivez les instructions. Utilisez Vérifier la copie pour contrôler le fichier avant la restauration.
  4. Vérifiez le profil et quelques observations de dates différentes avant de cesser d’utiliser l’ancien téléphone.

L’application conserve jusqu’à huit points de restauration locaux récents, y compris ceux créés manuellement. Ils restent sur le même appareil. Faites une sauvegarde externe avant de changer de téléphone, de désinstaller l’application ou d’effacer vos données.

Utilisation hors ligne

Continuez à noter vos observations

Dans l’application installée, la saisie quotidienne fonctionne hors ligne. Une connexion à Internet est nécessaire pour l’installation et les mises à jour.

La version web nécessite aussi une connexion à la première ouverture et lors de sa configuration dans le navigateur. Les observations restent sur votre appareil, sans synchronisation à distance entre téléphones.

Accès et confidentialité

Protéger l’accès sur votre appareil

La protection de l’accès est facultative et repose sur l’authentification de votre appareil. VitaChart reçoit le résultat sans accéder à vos données biométriques.

Sur iPhone, cette option masque le journal dans le sélecteur d’applications. Sur Android, elle empêche aussi les captures d’écran. Gérez séparément les sauvegardes exportées.

Réponses rapides

Questions fréquentes

Dois-je créer un compte ?

Vous pouvez utiliser VitaChart sans compte. Le journal reste sur votre appareil. L’application ne contient ni publicité ni outil d’analyse tiers.

Pourquoi mes observations n’apparaissent-elles pas sur mon autre téléphone ?

L’application ne synchronise pas les observations entre appareils. Pour transférer le journal, enregistrez une sauvegarde sur l’ancien téléphone, puis utilisez Charger la sauvegarde (Restaurer) sur le nouveau. Vérifiez vos observations avant de cesser d’utiliser l’ancien téléphone.

Le mode discret masque-t-il aussi les informations dans la sauvegarde ?

Le mode discret masque les rapports sexuels dans l’application et dans les rapports. La sauvegarde JSON conserve les données d’origine pour la restauration. Gardez le fichier dans un emplacement privé ou choisissez l’option chiffrée pour protéger votre copie exportée par un mot de passe.

Puis-je restaurer mon journal à partir d’un PDF ou d’un tableau ?

Le PDF sert à consulter, imprimer ou partager un rapport. Exporter le tableau (CSV / Excel) permet de consulter les données sous forme de tableau. Pour restaurer le journal dans l’application, utilisez une sauvegarde compatible.

Mon rappel ne s’est pas affiché. Que vérifier ?

Dans les réglages de votre appareil, vérifiez que VitaChart peut afficher des notifications, puis vérifiez l’heure réglée dans l’application. Si le rappel ne s’affiche toujours pas, indiquez-nous le modèle de l’appareil, la version du système, la version de l’application et l’heure du rappel.

Je ne retrouve plus mes observations. Comment obtenir de l’aide ?

Conservez vos sauvegardes et décrivez ce qui s’est passé avant que les observations ne disparaissent. Indiquez l’appareil, la version de l’application et si vous disposez d’une sauvegarde ou de points de restauration. Contactez-nous avant de supprimer des données ou de réinstaller l’application.

Besoin d’aide ?

Indiquez l’appareil et la version du système, les étapes suivies et ce qui s’est passé. Utilisez des données fictives pour illustrer le problème si nécessaire.
